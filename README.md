# Landlord Desk

Landlord Desk is a simple rental management web application built with React.

It helps landlords manage their rooms, tenants, rent payments, dues, and monthly payment history in one place.

## Features

* User Signup and Login
* Protected Dashboard
* Room Management
* Tenant Information
* Monthly Rent Tracking
* Paid and Due Amount Tracking
* Partial Payment Support
* Payment History
* Monthly Collection Summary
* Search Rooms
* Filter Rooms
* Sort Rooms
* Profile Management
* Dark and Light Mode
* Account Deletion
* Responsive Design

## Technologies Used

* React
* JavaScript
* React Router
* Tailwind CSS
* Vite
* LocalStorage

## How It Works

After creating an account, the user can log in and access the dashboard.

From the dashboard, the landlord can:

* Add and manage room information
* Manage tenant details
* Track monthly rent
* Record paid amounts
* See remaining dues
* Check previous payment history
* View monthly collection information
* Search, filter, and sort rooms

## Installation

Clone the repository:

YOUR_GITHUB_REPOSITORY_URL

Go to the project folder:

cd landlord_desk

Install dependencies:

npm install

Start the development server:

npm run dev

The application will run locally using Vite.

## Build

To create a production build:

npm run build
